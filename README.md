## 📌 Project Overview

NBA salaries are heavily right-skewed, creating massive disparities between raw on-court box-score outputs and true market financial capitalization. This repository hosts a dual-architecture machine learning engine designed to pinpoint asset inefficiencies. By normalizing salaries against fluctuating annual salary caps and utilizing a target log-transformed ensemble voting regressor, the platform maps player performance metrics against baseline contracts to discover the league's most overvalued and undervalued assets.

## 🏗️ Architecture Variants

This project has been split into two distinct execution branches to support different production and deployment requirements:

### ⚙️ 1. Dynamic Full-Stack Engine (Render Deployment)
The primary deployment relies on an active live server pipeline. Statistical vectors are piped continuously between the browser and a Python cloud container.

* **Live Feature Inference:** Powering the **Player Sandbox Laboratory**, allowing users to manually construct stat lines or hit **Shuffle Stats** to evaluate customized performance variables instantly.
* **Backend Stack:** Python, Flask API Routing, Scikit-learn (`VotingRegressor`, `TransformedTargetRegressor`), Pandas, NumPy.
* **Deployment Path:** Best hosted as a **Render Web Service** or hosted cloud container.

### 📄 2. Static Analytics Framework (GitHub Pages Deployment)
A lean, blazing-fast frontend-only deployment variant designed for zero-maintenance hosting directly over a global CDN.

* **Pre-Computed Data Mapping:** Reads directly from a pre-compiled data matrix (`nba_seasons_data.json`) generated by the core Python pipeline.
* **Frictionless D3 Exploration:** Renders the complete timeline matrix, dynamic scatter plot axis dimensions, feature importance weights, and full search-engine query indexing out of the box. *(Note: Dynamic Sandbox Lab calculations are stripped due to static environment rules).*
* **Deployment Path:** Hosted natively on **GitHub Pages**.

## 🛠️ Machine Learning Methodology

To push past traditional model limitations ($R^2$ ceilings under 50%), our pipeline introduces heavy structural upgrades:
1. **Target Log-Transformation:** Maps volatile, exponential salary structures efficiently into normalized linear distributions, lowering the overall Mean Absolute Error (MAE).
2. **Career Arc Modifiers:** Accounts for hard rookie-scale contract caps vs veteran extensions by adding non-linear tracking variables (`AGE_SQ`, `IS_ROOKIE_AGE`).
3. **Advanced Efficiency Ratios:** Introduces custom interaction variables like usage metrics and True Shooting approximations (`TS_PROX`) to penalize hollow, high-volume scorers.
