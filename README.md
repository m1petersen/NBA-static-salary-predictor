NBA Valuation Intelligence: Static Analytical Dashboard
Developed by Eclipse Analytics (Michael Petersen, Rajveer Barring, & Nikhil Ganpule)

This project is a lightweight, frontend-only analytical dashboard that explores the relationship between NBA player statistics and their contract valuations. Built for high-speed, zero-maintenance global delivery via GitHub Pages, this version relies on a pre-computed JSON dataset generated by our proprietary machine learning pipeline.

Core Features:

Pre-Computed Market Extremes: Users can explore pre-calculated market inefficiencies, easily identifying the most underpaid and overpaid players across multiple NBA seasons.

Interactive D3.js Visualizations: Features highly responsive scatter plots and bar charts that map feature importance weights and contract value spreads without the need for a live server.

Frictionless Exploration: By utilizing pre-processed data structures, the dashboard provides instant player search and filtering capabilities, offering a seamless data-exploration experience right in the browser.
